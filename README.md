# Учёт техники — Ганцевичская центральная районная библиотека

Система для сотрудников библиотеки. В ней можно хранить сведения о компьютерах и периферии, находить технику по инвентарному номеру, модели, кабинету или ответственному сотруднику и видеть, какие устройства к какому компьютеру привязаны.

Текущая версия: 1.1.0. История изменений — [CHANGELOG.md](CHANGELOG.md).

## Что можно делать

- учитывать компьютеры: инвентарный номер, модель, процессор, видеокарта, объём ОЗУ, накопитель, материнская плата, операционная система, кабинет, ответственный, дата ввода в эксплуатацию и примечания;
- учитывать периферию: мыши, клавиатуры, мониторы, принтеры, сканеры, ИБП и другие устройства со своим инвентарным номером;
- привязывать устройства к компьютерам и хранить технику без привязки;
- искать компьютеры и периферию по основным полям;
- фильтровать периферию по типу, компьютеру и признаку «без привязки»;
- видеть сводку: количество компьютеров, периферии, мониторов и устройств без привязки;
- добавлять, редактировать и удалять записи через формы;
- проверять уникальность инвентарных номеров без учёта регистра;
- сохранять периферию при удалении компьютера — устройства остаются в системе без привязки;
- работать на компьютере, планшете или телефоне.

## Подготовка

Потребуется Windows и установленные программы:

- [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) или новее;
- [Node.js](https://nodejs.org/) 18+ вместе с npm.

Проверить установку можно командами:

```powershell
dotnet --version
node --version
npm --version
```

## Запуск

В папке проекта запустите `start.cmd` двойным щелчком или командой:

```powershell
.\start.cmd
```

Скрипт установит недостающие зависимости, соберёт интерфейс и запустит сервер. После этого откройте <http://localhost:5169>.

Если нужно запустить части по отдельности:

```powershell
cd client
npm install
npm run build
cd ..\server
dotnet run
```

В этом случае интерфейс будет доступен по адресу: <http://localhost:5169>.

## Как пользоваться

### Компьютеры

Откройте вкладку **«Компьютеры»**. Нажмите **«Добавить компьютер»**, заполните форму и сохраните запись. В карточке компьютера видны характеристики, кабинет, ответственный, дата ввода в эксплуатацию и примечания. Ниже карточки отображается привязанная периферия.

Кнопками в карточке можно изменить или удалить компьютер. При удалении компьютера его периферия не исчезает, а остаётся в системе без привязки.

### Периферия

Откройте вкладку **«Периферия»**. Здесь можно добавить мышь, клавиатуру, монитор, принтер, сканер, ИБП или другое устройство, указать его инвентарный номер и при необходимости выбрать компьютер, к которому оно привязано.

Устройство можно изменить, удалить или отвязать от компьютера. Устройства без привязки видны в общем списке и через соответствующий фильтр.

### Поиск и фильтры

Строка поиска работает в обеих вкладках. Компьютеры можно искать по инвентарному номеру, модели, характеристикам, кабинету, ответственному и периферии. Для устройств доступны поиск и фильтры по типу, компьютеру и признаку «без привязки».

### Сводка

На главной странице отображаются количество компьютеров, периферии, мониторов и устройств без привязки. Эти числа обновляются после каждого изменения данных.

## Где хранятся данные

База данных находится в файле `server/library.db`. Она создаётся автоматически при первом запуске.

Для резервной копии остановите сервер и скопируйте файл `library.db`. Чтобы начать учёт с нуля, остановите сервер и удалите файлы `library.db`, `library.db-shm` и `library.db-wal` — при следующем запуске база создастся заново.

Файл базы содержит реальные инвентарные данные, поэтому его не нужно публиковать или пересылать без необходимости.

## Обновление

- Перед установкой новой версии сделайте резервную копию `server/library.db`.
- При запуске обновлённой версии структура базы данных обновляется автоматически; существующие записи сохраняются.
- Если при обновлении появится ошибка, восстановите резервную копию базы и проверьте, установлены ли необходимые компоненты (.NET 8 и Node.js).

## Важно

- Система предназначена для работы в локальной сети библиотеки и не содержит авторизации. Не публикуйте её в интернете без настройки доступа.
- Интерфейс полностью на русском языке.
- Перед обновлением версии обязательно делайте резервную копию базы данных.
