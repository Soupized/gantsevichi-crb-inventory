# История изменений

Все заметные изменения в этом проекте фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Статусы оборудования для компьютеров и периферии: «В эксплуатации», «В ремонте», «На складе», «Списан», поля даты и причины списания/вывода, фильтрация по статусу в интерфейсе.
- Резервное копирование и восстановление базы данных в формате SQLite (`.db`) из интерфейса.
- Экспорт и импорт данных в формате CSV (UTF-8) для компьютеров и периферии.
- Режим работы по локальной сети: по умолчанию сервер слушает `0.0.0.0:5169` (настраивается через `APP_URLS`), инструкция по развёртыванию для нескольких пользователей.
- Включён режим SQLite WAL для более стабильной совместной работы.

### Изменено

- Обновлена документация (README) с описанием сетевого режима, бэкапов, CSV и ограничений.

## [1.1.0] — 2026-11-18

### Добавлено

- Миграции схемы базы данных Entity Framework Core с поддержкой уже существующей базы без истории миграций.
- При попытке сохранить дублирующийся инвентарный номер показывается понятное сообщение вместо ошибки сервера.
- В интерфейсе добавлена обработка недоступности сервера и сетевых ошибок.

### Изменено

- Переход на миграции EF Core вместо создания схемы без истории миграций.
- Поиск выполняется на стороне базы данных.
- Включены внешние ключи SQLite.
- Скрипт `start.cmd` по умолчанию запускает приложение в режиме Production.
- Улучшены сообщения об ошибках при обращении к серверу.

## [1.0.0] — 2026-11-03

### Добавлено

- Учёт компьютеров и периферии, привязка устройств к компьютерам.
- Поиск и фильтрация, добавление/редактирование/удаление записей.
- Локальная база данных SQLite (`server/library.db`).
