# История изменений

Все заметные изменения фиксируются в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## [Не выпущено]

## [1.1.0] — 2026-11-18

### Исправлено

- восстановлена корректная кодировка русского текста в интерфейсе, сообщениях проверки данных и служебных файлах;
- при попытке сохранить повторяющийся инвентарный номер возвращается понятное сообщение вместо сбоя сервера, включая случаи одновременных запросов;
- при недоступности сервера интерфейс показывает понятное сообщение о проблеме подключения.

### Улучшено

- база данных переведена на миграции Entity Framework Core: существующая база автоматически подготавливается и обновляется при запуске новой версии без потери записей;
- поиск компьютеров и периферии выполняется на стороне базы данных;
- при удалении компьютера связанные устройства отвязываются на уровне базы данных;
- включён контроль внешних ключей SQLite;
- скрипт `start.cmd` по умолчанию запускает приложение в рабочем режиме;
- обновлены инструкция для сотрудников и примечания к выпуску.

## [1.0.0] — 2026-11-03

Первая версия системы учёта компьютерной техники и периферии Ганцевичской центральной районной библиотеки.

### Добавлено

- учёт компьютеров: инвентарный номер, модель, характеристики, кабинет, ответственный, дата ввода в эксплуатацию и примечания;
- учёт периферии: мыши, клавиатуры, мониторы, принтеры, сканеры, ИБП и другие устройства со своим инвентарным номером;
- привязка периферии к компьютеру и работа с устройствами без привязки;
- добавление, изменение и удаление записей через интерфейс;
- поиск по основным полям и фильтры по типу устройства, компьютеру и признаку «без привязки»;
- сводка по количеству компьютеров, периферии, мониторов и устройств без привязки;
- проверка уникальности инвентарных номеров без учёта регистра между компьютерами и устройствами;
- автоматическое создание базы данных при первом запуске;
- сохранение периферии при удалении компьютера: устройства остаются в системе без привязки;
- адаптивный интерфейс для компьютеров, планшетов и телефонов;
- запуск одним скриптом `start.cmd` и инструкция для сотрудников в `README.md`.

### Безопасность

- Приложение не содержит авторизации и предназначено для локальной сети библиотеки.
- Файл базы данных `server/library.db` содержит реальные инвентарные данные и не должен попадать в репозиторий.
