# История изменений

Все заметные изменения в этом проекте документируются в этом файле.  
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [1.3.0] - 2026-11-25

### Добавлено

- Авторизация по паролю: защита API и экрана входа, кнопка «Выйти». Пароль задаётся переменной `INVENTORY_PASSWORD`, а при её отсутствии автоматически создаётся файл `server/auth-password.txt`.
- Глобальный реестр инвентарных номеров и SQLite-триггеры: одинаковый номер не может быть сохранён одновременно у компьютера и устройства, включая прямой доступ к базе.

### Изменено

- Проверка уникальности инвентарных номеров переведена с SQLite `NOCASE` на Unicode-нормализацию в приложении; корректно обрабатываются регистр кириллицы, пробелы и совпадения между таблицами.
- Импорт CSV использует ту же нормализацию: дубликаты внутри файла и конфликты с уже существующими компьютерами/устройствами отклоняются до сохранения.
- После восстановления базы из `.db` автоматически повторно применяются миграции и перестраивается реестр инвентарных номеров.

### Исправлено

- Устранена возможность сохранения одного инвентарного номера для компьютера и периферии.
- Обновлена документация по авторизации, уникальности инвентарных номеров и текущей версии.

## [1.2.0] - 2026-11-18

### Добавлено

- Статусы оборудования для компьютеров и периферии: «В эксплуатации», «В ремонте», «На складе», «Списан», поля даты и причины списания/вывода, отображение и фильтрация в интерфейсе.
- Резервное копирование и восстановление базы данных в формате SQLite (`.db`) через раздел «Данные».
- Экспорт и импорт данных в формате CSV (UTF-8 с BOM) для компьютеров и периферии. Импорт добавляет новые записи и обновляет существующие по инвентарному номеру (привязка периферии к компьютеру — по `ComputerInventoryNumber`).
- Доступ по локальной сети: `start.cmd` по умолчанию запускает приложение на `http://0.0.0.0:5169` (адрес можно переопределить переменной `APP_URLS`).
- Режим SQLite WAL для более стабильной работы при одновременном доступе.

### Изменено

- Поиск и фильтрация списков выполняются на стороне сервера (запросы к API с параметрами поиска, статуса, типа и привязки), без дублирующей локальной выборки на клиенте.
- Инвентарный номер должен быть глобально уникальным для всех компьютеров и устройств; проверки выполняются без учёта регистра в приложении и при импорте CSV (включая дубликаты внутри файла).
- Обновлена документация: инструкции по резервным копиям, CSV, работе в локальной сети, статусам и ограничениям. Интерфейс адаптивен для разных размеров экрана и доступен из браузера по адресу сервера в локальной сети (отдельное мобильное приложение не входит в состав проекта).

### Исправлено

- Восстановлена корректная кодировка русских текстов в интерфейсе, сообщениях API/валидации и документации.
- Уточнены сообщения об ошибках при резервном копировании, восстановлении и проверке уникальности инвентарных номеров.

## [1.1.0] - 2026-11-18

### Добавлено

- Переход на Entity Framework Core и миграции для создания и обновления схемы базы данных.
- Автоматическая подготовка (baseline) существующей базы при первом запуске с миграциями.

### Изменено

- При запуске автоматически применяются ожидающие миграции EF Core.
- Поиск компьютеров и периферии выполняется на стороне базы данных.
- Включён контроль внешних ключей SQLite.
- `start.cmd` по умолчанию запускает приложение в рабочем режиме (Production).

### Исправлено

- Восстановлена корректная кодировка русского текста в интерфейсе, сообщениях об ошибках и документации.
- При попытке сохранить уже используемый инвентарный номер показывается понятное сообщение.
- Улучшена обработка ошибок подключения к серверу в интерфейсе.

## [1.0.0] - 2026-11-03

### Добавлено

- Учёт компьютеров и периферийного оборудования с основными характеристиками и привязкой устройств к компьютерам.
- Поиск, фильтрация, добавление, редактирование и удаление записей.
- Локальная база данных SQLite (`server/library.db`).
