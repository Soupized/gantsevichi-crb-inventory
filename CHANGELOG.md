# История изменений

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [семантическому версионированию](https://semver.org/lang/ru/).
Правила ведения версий описаны в [docs/VERSIONING.md](docs/VERSIONING.md).

## [Не выпущено]

### Планируется

- авторизация и роли пользователей;
- экспорт списков техники в Excel/PDF;
- история перемещений и ремонтов оборудования;
- печать инвентарных QR-кодов;
- резервное копирование базы из интерфейса.

## [1.0.0] — 2026-11-03

Первая рабочая версия для учёта компьютерной техники Ганцевичской центральной
районной библиотеки.

### Добавлено

- Backend на ASP.NET Core Web API (.NET 8) с Entity Framework Core и SQLite.
- Модели `Computer`, `Device` и перечисление типов устройств
  (`Mouse`, `Keyboard`, `Monitor`, `Printer`, `Scanner`, `Ups`, `Other`).
- CRUD API для компьютеров: создание, чтение, изменение и удаление.
- CRUD API для периферии с привязкой устройства к компьютеру.
- Поиск компьютеров по инвентарному номеру, модели, комплектующим, кабинету,
  ответственному и периферии.
- Фильтрация устройств по типу, компьютеру и признаку «без привязки».
- Проверка уникальности инвентарных номеров без учёта регистра между
  компьютерами и устройствами.
- Автоматическое создание базы SQLite при первом запуске.
- Сохранение периферии при удалении компьютера: устройства остаются в системе
  без привязки.
- Swagger/OpenAPI для документации API в режиме Development.
- React-интерфейс на Vite с адаптивной вёрсткой:
  - карточки компьютеров с характеристиками и списком периферии;
  - таблица устройств с поиском и фильтрами;
  - сводная статистика по технике;
  - формы добавления и редактирования;
  - подтверждение удаления и уведомления об операциях.
- Скрипт `start.cmd` для установки зависимостей, сборки клиента и запуска сервера.
- README с инструкцией по установке, запуску и описанием API.
- Примеры HTTP-запросов в `server/LibraryInventory.Api.http`.
- `.gitignore` для исключения базы данных, `node_modules`, `bin`, `obj` и
  собранного клиента.

### Проверено

- создание и редактирование компьютера;
- добавление периферии с привязкой к компьютеру;
- поиск и фильтрация;
- удаление компьютера с сохранением периферии без привязки;
- удаление устройства;
- отсутствие ошибок JavaScript в браузере;
- запуск проекта с чистой базы данных через `start.cmd`.

### Безопасность

- Приложение не содержит авторизации и предназначено для локальной сети
  организации.
- Файл базы данных `server/library.db` не должен попадать в Git: он содержит
  реальные инвентарные данные.
