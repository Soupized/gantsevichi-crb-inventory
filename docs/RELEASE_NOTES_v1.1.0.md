# 1.1.0 — исправления и обновление базы данных

Обновление повышает надёжность системы при длительной эксплуатации и подготовке к будущим версиям.

## Исправлено

- восстановлена корректная кодировка русского текста в интерфейсе, сообщениях об ошибках и документации;
- при попытке сохранить уже используемый инвентарный номер система показывает понятное сообщение, а не ошибку сервера;
- при недоступности сервера интерфейс сообщает о проблеме подключения.

## Улучшено

- база данных переведена на миграции Entity Framework Core;
- при запуске новой версии существующая база `library.db` автоматически подготавливается и обновляется без потери записей;
- поиск компьютеров и периферии выполняется на стороне базы данных;
- включён контроль внешних ключей SQLite;
- скрипт `start.cmd` по умолчанию запускает приложение в рабочем режиме.

## Обновление

1. Остановите приложение и сделайте резервную копию `server/library.db`.
2. Установите новую версию поверх старой.
3. Запустите `start.cmd` и откройте <http://localhost:5169>.

Подробная инструкция — в `README.md`.
