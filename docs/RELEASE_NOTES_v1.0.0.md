# 1.0.0 — первая версия

Первая рабочая версия системы учёта компьютерной техники для Ганцевичской
центральной районной библиотеки.

## Что умеет

- вести учёт компьютеров: инвентарный номер, модель, процессор, видеокарта,
  объём ОЗУ, накопитель, материнская плата, операционная система, кабинет,
  ответственный, дата ввода в эксплуатацию и примечания;
- вести учёт периферии: мыши, клавиатуры, мониторы, принтеры, сканеры, ИБП и
  другие устройства с собственными инвентарными номерами;
- привязывать периферию к компьютерам и работать с устройствами без привязки;
- искать технику по инвентарному номеру, модели, характеристикам, кабинету и
  ответственному;
- фильтровать периферию по типу, компьютеру и признаку «без привязки»;
- видеть сводку: количество компьютеров, периферии, мониторов и устройств без
  привязки;
- добавлять, редактировать и удалять записи через интерфейс;
- проверять уникальность инвентарных номеров без учёта регистра;
- сохранять периферию при удалении компьютера — устройства остаются в системе
  без привязки.

## Технологии

- C# / .NET 8, ASP.NET Core Web API;
- Entity Framework Core 8, SQLite;
- React 18, Vite 5, HTML5, CSS3;
- Swagger / OpenAPI.

## Запуск

```powershell
.\start.cmd
```

Откройте <http://localhost:5169>. Подробная инструкция — в `README.md`.

## Проверено

- создание и редактирование компьютера;
- добавление периферии с привязкой к компьютеру;
- поиск и фильтры;
- удаление компьютера с сохранением периферии без привязки;
- удаление устройства;
- запуск с чистой базы данных;
- отсутствие ошибок JavaScript в браузере.

## Важно

- приложение рассчитано на локальную сеть организации и не содержит авторизации;
- база данных `server/library.db` не входит в репозиторий и содержит реальные
  инвентарные данные;
- перед обновлением версии делайте резервную копию базы данных.
